- Un software que permite monitorear el estado del servidor cuya dirección IP pública se introduzca en la barra de la aplicación. Devuelve datos de salud (uptime, carga, memoria, disco o estado general), estado general (OK, alerta, caído), métricas principales, último chequeo y un historial corto de eventos.
